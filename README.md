# 🌿 Paradise Nursery - Shopping Cart Application

## 📌 Project Overview
This project is a shopping cart application for an online plant shop called **Paradise Nursery**. The application allows users to browse a variety of house plants, add them to a cart, and manage their selections before checkout.

---

## 🎯 Features

### 🏠 Landing Page
- Introductory page for Paradise Nursery
- Button to navigate to the product listing page

### 🔗 Navigation Bar
- Accessible on all pages
- Links to:
  - Landing Page
  - Product Listing Page
  - Shopping Cart Page

### 🌱 Product Listing Page
- Displays multiple house plants
- Each plant is shown in a **card layout** including:
  - Image
  - Name
  - Description
  - Price
  - Add to Cart button

- Plants are grouped into at least two categories:
  - 🌸 Aromatic Plants
  - 🌿 Medicinal Plants

---

### 🛒 Shopping Cart Page
- Displays all items added to the cart
- Each item includes:
  - Thumbnail image
  - Plant name
  - Unit price
  - Total price (based on quantity)

- Users can:
  - ➕ Increase quantity
  - ➖ Decrease quantity
  - ❌ Remove item from cart

- Additional actions:
  - Continue Shopping
  - Checkout
